# Axion — Portfólio de tecnologia

Portfólio responsivo para a marca **Axion**, com a mensagem:

> Construímos sistemas. Transformamos negócios.

## Arquivos

- `index.html` — estrutura, conteúdo e seções do portfólio.
- `style.css` — identidade visual, layout responsivo e elementos gráficos.
- `script.js` — menu mobile, ano automático e links de WhatsApp.

## Rodar localmente

1. Extraia o ZIP.
2. Abra a pasta no VS Code.
3. Abra `index.html` no navegador ou use a extensão Live Server.

## WhatsApp configurado

O número já está configurado em `script.js` como `5511974965614`.
O link abre uma conversa com uma mensagem inicial. Faça um teste no celular e no computador antes de publicar.

## Antes de divulgar

- Revise o texto e confirme que os serviços listados correspondem ao que você oferece.
- Os três projetos são **conceitos demonstrativos**, não trabalhos reais de clientes. Mantenha essa informação até substituir os exemplos por projetos reais.
- As fontes usam Google Fonts e precisam de internet para carregar; o restante do layout não depende de imagens externas.
- Confira domínio, redes sociais e disponibilidade jurídica do nome Axion antes de investir na marca.
- Publique em um serviço de hospedagem estática e teste os links, a navegação mobile e o formulário de contato (este modelo usa WhatsApp, não formulário).
